# for-fun-game-attempt
## Text Based Adventure Game Development


* This is a for fun practice to try and put into work all of the things I learned in class.
* This game is trying to be made in the same vein as, for example, Hitchhiker's Guide to the Galaxy text-adventure game that is available on the BBC website.
* This is a hobby-attempt and mostly for practice, so there is no guarantee that this will get updated frequently.
* Will try to make sure this project stays somewhat up-to-date with my lessons in class.

This project will be made entirely in C using Visual Studio Code.
As well, are ASCII art used in the game can be found [here in this ASCII art gallery](https://www.asciiart.eu/gallery).

This is not a professional work!
